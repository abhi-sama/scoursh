What scoursh detects

The full built-in check catalogue on the dev branch, grouped by scan surface and by what each check needs to run. Roughly 180 checks ship in the box.

Almost everything runs with no external data. Point scoursh at source code (--path) or a live app (--target) and every SAST, IaC, and DAST check below works immediately — no database, no downloads, no network. Only dependency-CVE scanning (SCA) and one banner check need the vendored advisory database.

Optional engine depth --use-engines

Vendor a specialist engine (you pin its version + checksum) and --use-engines runs it as an adapter for extra depth, keeping scoursh's honest coverage accounting. These add depth to existing surfaces, not new categories.
