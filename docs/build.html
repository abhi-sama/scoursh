Command builder

Pick a surface, point it at a path or target, toggle options, and copy the exact scan.sh invocation. This page composes a command string only — it never runs anything, and it makes no network request of any kind. The terminal equivalent is ./scan.sh <command> --guided --print-command, which asks the same questions interactively and prints the command instead of running it. See also docs/checks.html for what each check needs, and docs/USAGE.md for the full flag reference.
