# SQL database error signatures (docs/DESIGN.md §7.3 SQLi (a) error-based:
# "inject ' / " and diff for DB error signatures").
#
# One ERE per line, matched case-insensitively against a response body through
# scan_match (the frozen portable ERE subset, rules/RULE-FORMAT.md - no
# backreferences, no PCRE). A match that appears in an injected response but not
# in the benign baseline is the error-based signal. These describe error TEXT a
# database driver emits; describing the shape rather than a specific product is
# the same target-agnostic discipline the SAST/IaC rule packs follow.
